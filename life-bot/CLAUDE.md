# CLAUDE.md

Контекст проекта. Читается автоматически в начале каждой сессии.

## Что это

Личный Telegram-бот для одного пользователя: приём заметок, напоминаний, списков и данных о питании текстом, голосом и фото. Задание целиком — в `docs/`.

## Документы, которые нужно прочитать перед работой

| Файл | Что внутри |
|---|---|
| `docs/life_bot_spec.md` | Техзадание, порядок работ, приёмочные сценарии |
| `docs/life_bot_schema.sql` | Схема SQLite. Утверждена, применяется как есть |
| `docs/life_bot_parsing.md` | Слои разбора входящих и промпты для моделей |
| `docs/life_bot_replies.md` | Тексты ответов бота. Воспроизводятся дословно |

## Правила работы над этим проектом

1. Схему данных и тексты ответов не переписывать. Они утверждены отдельно. Если считаешь, что в них ошибка — скажи, не правь молча.
2. При неоднозначности требования спрашивай. Не додумывай.
3. Этапы делаются по порядку. Следующий не начинается, пока приёмочные сценарии текущего не проходят.
4. Каждый этап заканчивается работающим ботом, а не заготовкой.
5. Ничего не изобретать там, где есть готовая библиотека из списка в спеке.

## Стек

Python 3.11+, aiogram 3, aiogram-dialog, APScheduler, dateparser, python-dateutil, faster-whisper, SQLite в WAL.

Разбор свободного текста — через Claude Code CLI в headless-режиме на подписке владельца: `claude -p --model haiku --output-format json`. Обязательны таймаут, один повтор и `--fallback-model`.

## Среда

- Прод: VPS Ubuntu, systemd с `Restart=always`.
- Часовой пояс пользователя Europe/Moscow. В базе всё в UTC.
- Секреты в отдельном файле с правами 600, в репозиторий не попадают.
- Версия Claude Code CLI зафиксирована, обновляется осознанно.

## Тон текстов

Сухо, фактами, короткими строками. Без «отлично», «готово», восклицательных знаков и эмодзи в текстах бота. Даты словами с сокращённым днём недели: `15 октября (чт)`.

## Чего в этом проекте нет

Home Assistant, маркетплейсы, рабочие задачи, веб-интерфейс, приоритеты, теги, геймификация. Всё это осознанно вынесено за скоуп.
