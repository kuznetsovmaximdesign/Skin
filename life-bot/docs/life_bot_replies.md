# Ответы бота

## Жизненный цикл сообщений

Чат не должен превращаться в ленту. Отсюда три правила.

**Редактируется, а не отправляется заново:**
- закреплённый счётчик;
- список просроченного — обновляется на месте, дубли не плодятся;
- карточка записи при правке;
- вопрос-уточнение: после ответа переписывается в подтверждение, кнопки исчезают;
- листание списков `/where`, `/wish`, `/gifts` — на месте, без новых сообщений.

**Отправляется новым сообщением:**
- напоминание в момент срока — это событие, его нельзя пропустить;
- подтверждение записи — ответом на твоё сообщение, чтобы было видно, к чему относится;
- итог дня по еде.

**Не отправляется никогда:**
- пустые сводки без твоего запроса;
- повторное подтверждение того же самого;
- служебные сообщения об успехе внутренних операций.

## Прозрачность

1. Каждое подтверждение — реплай на исходное сообщение. Видно, что чем подтверждено.
2. После нажатия кнопки сообщение переписывается в результат, кнопки убираются: `ОСАГО. Отложено на завтра, 10 сентября (чт).` Мёртвых кнопок в чате не остаётся.
3. Один объект — одно живое сообщение. Открыл карточку записи второй раз — предыдущая сворачивается в строку.
4. Повторное нажатие той же кнопки не создаёт второе действие.
5. `/find` → карточка → история: по записи видно, что и когда менялось — показывает, что и когда менялось.

## Правила формулировки

1. Одна строка. Ориентир — до десяти слов.
2. В строке только то, что могло быть распознано неверно: дата, число, имя, тип записи. Остальное не повторяется.
3. Даты словами, с сокращённым днём недели в скобках: `15 октября (чт)`. Ошибку видно сразу по двум признакам, а не по одному.
4. Сокращения дней недели: пн, вт, ср, чт, пт, сб, вс. Строчными, без точки.
5. Год называется, только если он не текущий: `15 января 2027 (пт)`.
6. «Сегодня» и «завтра» пишутся словом, без дня недели — они и так однозначны.
7. Никаких «готово», «отлично», «добавлено в базу», эмодзи и восклицательных знаков.
8. Реакция на сообщение остаётся как быстрый визуальный сигнал, но текст теперь основной.

## Подтверждение записи

| Событие | Ответ |
|---|---|
| Срок | `Напомню 15 октября (чт) — ОСАГО.` |
| Срок с подготовкой | `Напомню 15 сентября (вт). Событие 15 октября (чт).` |
| Повторяющийся | `Напомню 15 октября (чт), каждый год.` |
| Ближайшие дни | `Напомню завтра — забрать посылку.` |
| Еда | `Борщ. 320 ккал, 18 г белка.` |
| Пробег | `Пробег 45300. До ТО около 4700 км.` |
| Заправка | `Заправка 3200 ₽ при 45300.` |
| Вишлист | `В вишлист: наушники Sony, 15000.` |
| Подарок | `Подарок Кристине: сумка, 8000.` |
| Место | `Место: Depo, Москва.` |
| Событие с датой | `Место: выставка, до 30 ноября (пн).` |
| Несколько фактов | `Записал 3: срок 20 октября (вт), место Depo, вишлист наушники.` |
| Не разобрал | `Не понял, отложил.` |

Данные, приходящие из Home Assistant, не подтверждаются вообще: ты их не отправлял.

## Уточнение

Задаётся, когда модель не уверена. Вопрос короткий, вариантов не больше трёх, ответ принимается кнопкой, текстом или голосом.

```
Пятница — 11 или 18 сентября?
[11 сентября (пт)] [18 сентября (пт)] [это новое]
```

```
Подарок для кого?
[Кристина] [мама] [сказать голосом]
```

## Закреплённое сообщение — счётчик

Аналог бейджа на иконке приложения. Одно сообщение, закреплённое в чате, бот его редактирует, а не отправляет заново.

```
Просрочено 2 · Сегодня 1 · Инбокс 3
```

Когда всё чисто:

```
Чисто.
```

Обновляется при любом изменении состояния. Тихих часов не касается — редактирование закреплённого не шлёт уведомление.

## Заметки и покупки

Заметка:

```
Записал.
```

Голосовой запрос «что я записывал про подрядчика»:

```
14 августа: телефон подрядчика по кровле, Сергей, 8 916 ...
[удалить] [ещё 2]
```

Списки покупок: продукты и домой. Добавление пачкой — «молоко, хлеб, творог»:

```
В продукты: молоко, хлеб, творог.
```

Запрос «что купить домой»:

```
Домой: лампочки · фильтр для воды
[лампочки] [фильтр] [очистить список]
```

Нажатие на позицию вычёркивает её, сообщение переписывается на месте.

## Недельная сводка с советом

Приходит в воскресенье. Совет выдаётся, только если один и тот же паттерн повторился минимум три раза. Иначе остаются одни цифры.

```
Неделя: закрыто 4, перенесено 3, просрочено 1.
Все три переноса — документы.
Совет: ставь документы на выходные, в будни ты их не делаешь.
```

Без оснований для совета:

```
Неделя: закрыто 4, перенесено 1.
```

Если за неделю не было ни одного закрытия и ни одной записи — сводка не отправляется.

## Закрытие просроченного

Если запись просрочена больше суток, «сделал» раскрывается:

```
Когда сделал?
[сегодня] [вчера] [в срок]
```

## Напоминание в момент срока

```
ОСАГО.
[сделал] [не напоминать]
[через час] [завтра] [через неделю]
```

Просрочка. Всё просроченное приходит одним сообщением, а не по одному:

```
Просрочено:
ОСАГО — 3 дня.
Оплатить интернет — 1 день.
[ОСАГО сделал] [интернет сделал]
[всё через час] [всё завтра]
```

Одна позиция:

```
ОСАГО — третий день, четвёртое напоминание.
[сделал] [через час] [завтра] [через неделю]
```

При переносе подтверждение снова с днём недели:

```
Перенёс на 22 октября (чт).
```

```
Белок 78 из 120. Калории 2140 из 1900.
```

Если за день не было ни одной записи — сообщение не отправляется.

## Разбор инбокса

Запускается при пяти неразобранных или через две недели, что раньше.

```
5 неразобранных. Начнём?
[да] [позже]
```

Дальше по одному, с исходным текстом сообщения и вариантами типа.

## Ответы на команды

Команды регистрируются латиницей — таково требование Telegram. В меню видно русское описание.

| Команда | Описание в меню |
|---|---|
| `/today` | Что сегодня |
| `/find` | Найти запись |
| `/buy` | Списки покупок |
| `/notes` | Заметки |
| `/where` | Куда сходить |
| `/watch` | Что посмотреть |
| `/wish` | Вишлист |
| `/gifts` | Подарки |
| `/car` | Пробег и ТО |
| `/food` | Итог дня |
| `/inbox` | Разобрать неразобранное |
| `/export` | Выгрузить базу |

Постоянная клавиатура внизу — русская: Сегодня · Покупки · Заметки · Списки.

`/today`, когда пусто:

```
На сегодня ничего.
```

`/today` со сроками:

```
Сегодня (ср): оплатить интернет.
Просрочено: ОСАГО, третий день.
```

`/where`:

```
Depo, Москва. Советовала Кристина.
Зарядье, прогулка.
Гараж, бар.
```

`/watch`:

```
Дюна 2. Советовал Дима.
Оппенгеймер.
Ещё один фильм.
[посмотрел] [ещё 3]
```

`/car`:

```
Пробег 45300 на 9 сентября (ср). Около 1200 км в месяц.
ТО ориентировочно в декабре.
```

## Сбой

```
Не разобрал, сохранил как есть.
```

Причина сбоя пользователю не объясняется — она пишется в лог. Пользователю важно только то, что запись не потеряна.
