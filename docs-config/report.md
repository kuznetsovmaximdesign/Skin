# Отчёт о разборе портала (ОБРАЗЕЦ)

Этот файл сервис не разбирает — он нужен людям как контекст и обоснование правил.
Замените его отчётом из разбора.

Ключевые выводы, на которых построены правила:

- на портале сосуществуют несколько поколений шаблона; правила одного поколения нельзя
  применять к другому;
- цвет врезки не означает её тип: в разных продуктах один цвет используется по-разному;
- `article_id` связывает языковые версии, но совпадение структуры не означает синхронного
  обновления — даты расходятся;
- часть выводов остаётся открытыми вопросами и проверяется на уровне рекомендаций.
