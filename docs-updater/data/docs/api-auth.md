# Авторизация в API

## Назначение

Документ описывает, как получить токен доступа и использовать его в запросах к публичному API.

## Предварительные условия

- Учётная запись с ролью «Интегратор».
- Выпущенная пара `client_id` и `client_secret`.
- Доступ к хосту `api.example.local`.

## Получение токена

1. Отправьте запрос `POST /v1/auth/token` с полями `client_id` и `client_secret`.
2. Сохраните значение поля `access_token` из ответа.
3. Передавайте токен в заголовке `Authorization: Bearer <access_token>`.

## Срок жизни токена

Токен действует 60 минут. После истечения срока запросите новый токен тем же способом.

## Ограничения

- Не более 10 запросов на выпуск токена в минуту.
- Токен нельзя отозвать вручную, он гасится по истечении срока.
