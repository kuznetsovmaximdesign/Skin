# Установка агента сбора данных

## Назначение

Документ описывает установку локального агента, который передаёт метрики в систему мониторинга.

## Предварительные условия

- Linux с systemd, версия ядра 5.10 или выше.
- Права root на сервере.
- Открытый исходящий порт 8443 до коллектора.

## Установка

1. Скачайте пакет агента из внутреннего репозитория.
2. Установите пакет командой пакетного менеджера дистрибутива.
3. Пропишите адрес коллектора в файле `/etc/collector/agent.yaml`.
4. Запустите службу и добавьте её в автозагрузку.

## Проверка работы

Через 2 минуты после запуска агент появляется в списке источников в разделе «Мониторинг».

## Ограничения

- Один агент на один сервер.
- Метрики отправляются раз в 60 секунд.
