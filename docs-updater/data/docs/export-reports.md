# Экспорт отчётов

## Назначение

Документ описывает выгрузку отчётов из раздела «Аналитика» в файлы.

## Предварительные условия

- Роль «Аналитик» или выше.
- Готовый отчёт в разделе «Аналитика».

## Форматы выгрузки

- CSV — для последующей обработки в таблицах.
- XLSX — для готовых сводных таблиц.

## Как выгрузить отчёт

1. Откройте отчёт в разделе «Аналитика».
2. Нажмите **Экспорт** в правом верхнем углу.
3. Выберите формат и период.
4. Дождитесь письма со ссылкой на файл.

## Ограничения

- Максимальный период выгрузки — 90 дней.
- Ссылка на файл действует 24 часа.
