# Формат, выведенный из образцов

Разобрано документов: 1 (sample-doc.md).

- Порядок разделов как в образцах: Назначение → Ограничения.
- Обращение к читателю — на «вы».
- Не писать от первого лица («мы сделали»).
- Предложения короткие: в образцах в среднем 4.0 слов, держаться в пределах 12.
- Абзац — примерно 1.0 предложения, длинные абзацы разбивать.
- Маркированные списки — символом «-».
- Нумерованные списки — в формате «1.».
- Заголовки: с заглавной только первое слово.
- Без восклицательных знаков.
