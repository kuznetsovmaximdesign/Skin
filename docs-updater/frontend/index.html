Не найдена дизайн-система HEXA

Интерфейс собран на компонентах HEXA, а её файлы в репозиторий не выкладываются. Положите их в папку frontend/vendor/hexa/:

frontend/vendor/hexa/_ds_bundle.js
frontend/vendor/hexa/_ds_bundle.css
frontend/vendor/hexa/styles.css
frontend/vendor/hexa/fonts/fonts.css

Взять их можно из выгрузки дизайн-системы: папка _ds/kaspersky-hexa-ui-…/. Проще всего — командой из папки сервиса:

python3 install_ui.py путь/до/выгрузки.zip

Сам сервис при этом работает: описание API доступно всегда.
